Краткое описание

«Угадай слово» — автономная логическая игра, созданная MGGamesStudio.

Системные особенности

- Игра поставляется в виде самостоятельного приложения.
- Сохраняемые данные создаются локально на устройстве пользователя.
- Для отображения интерфейса используются собственные графические материалы и сторонние компоненты, указанные в THIRD-PARTY-NOTICES.txt.
